# Plan — MVP como PWA (web), manteniendo la nativa para después

**Fecha:** 2026-06-12 · **Rama:** `feat/pwa-mvp`
**Contexto:** lanzar primero una **PWA** para testear en campos reales (sin coste de
tiendas), reutilizando el código Expo existente. La nativa (react-native-maps) se
publicará más adelante desde el mismo repo. Decidido con el usuario.

## Qué se reutiliza (ya funciona en web hoy)
Dominio, servicios (courses, storage), onboarding, bolsa, perfil, selección de campo
y el motor de recomendación. GPS vía **expo-location** (soporta foreground en web).
`expo export --platform web` ya pasa. Solo falta: el **mapa web** y el **empaquetado PWA**.

## Decisiones (defaults)
- **Leaflet** (sin react-leaflet) + **Esri World Imagery** (satélite gratis, atribución,
  sin API key). Marcadores/chips con `divIcon` (HTML), sin imágenes de marcador.
- PWA: `manifest.json` + meta iOS (añadir a inicio) + **service worker** (cachea shell,
  datos de campos y teselas vistas → offline tras 1ª visita).
- `web.output: "single"` (SPA) para que el SW resuelva navegaciones contra `index.html`.

## Trabajo
1. **Deps:** `npm i leaflet` + `npm i -D @types/leaflet`.
2. **`src/ui/components/hole-map.web.tsx`** — reescribir como mapa Leaflet real con el
   **mismo contrato de props** que el nativo: tiles satélite, polígono del green,
   línea de juego, marcador GPS (inicial), objetivo **arrastrable** (anillo beige,
   centro transparente), líneas GPS→objetivo y objetivo→green con chips
   (distancia + palo), `fitBounds` al hoyo, `click`/`dragend` → `onMoveTarget`.
   - Colores/estilos desde `theme` (HTML de los divIcon).
3. **`app/+html.tsx`** — documento HTML raíz (solo web): viewport, `theme-color`,
   `manifest`, meta apple (`apple-mobile-web-app-*`, `apple-touch-icon`), CSS de Leaflet
   (CDN, cacheada por el SW) y registro del service worker (fuera de localhost).
4. **`public/manifest.json`** — name, short_name, start_url, display standalone,
   background/theme color, orientation portrait, icons.
5. **`public/sw.js`** — runtime caching: navegaciones → red con fallback a cache;
   estáticos same-origin → stale-while-revalidate; teselas Esri + CSS Leaflet →
   cache-first con tope. (MVP sin Workbox.)
6. **`public/icon.png`** — copia del icono para manifest/apple-touch.
7. **`app.json`** — `web.output: "single"`, `web.themeColor`, `web.backgroundColor`.
8. **Docs de despliegue** — `dist/` estático → Netlify/Vercel/Cloudflare Pages (raíz).
   GitHub Pages necesitaría `baseUrl` (lo anotamos).

## Verificación
- `typecheck` (con @types/leaflet + DOM), `lint`, `test` (122 siguen verdes — el mapa
  web no es testeable en jest-expo; el nativo sí con su mock).
- `expo export --platform web` (la prueba de que la PWA compila con Leaflet).
- Servir `dist/` y comprobar manifest + SW; **prueba real en móvil la hace el usuario**.

## Riesgos / notas
- iOS Safari puede purgar el almacenamiento de PWAs no usadas ~7 días → mitigar
  animando a "Añadir a inicio" (más persistente). Backup/export de bolsa: futuro.
- El fondo satélite necesita cobertura (igual que en nativo); el SW cachea lo visto.
- El botón "Simular GPS" es `__DEV__` → no sale en el build de producción.
